CivicTrack frontend

1. Open this folder in VS Code.
2. Set the backend address in config.js.
3. Start the backend and serve index.html with VS Code Live Server (or another local HTTP server).
4. Use the registration form to create a citizen account. Administrator accounts must be created/assigned by the project administrator in MySQL; public registration always creates a citizen account.

Use HTTPS or localhost for browser location access. Do not open index.html using a file:// URL.
